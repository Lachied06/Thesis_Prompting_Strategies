# MIT software licence scope

The author confirmed permission to publish and MIT-license the original thesis software. [LICENSE](LICENSE) applies only to the exact 72 software paths enumerated in [LICENSE_SCOPE.json](LICENSE_SCOPE.json): implementation, tests, offline tools, original project configuration/dependency files and software prompt templates/registry metadata. The original files themselves were not edited to insert headers.

This is not a blanket licence over the repository. Raw/processed datasets, supplied-source text, rendered generation/judge requests, model responses, annotations, statistical exports, figures, the thesis manuscript and other unlisted material are outside the MIT grant. Two explicitly listed project configuration files happen to reside below data/raw/; the dataset text beside them is not MIT-licensed. See [DATA_LICENSES.md](DATA_LICENSES.md) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

The copyright-holder line intentionally refers to the original software copyright holders rather than inferring sole ownership from a manuscript byline, university front matter or workbook properties. The operative authorisation is the author's current D1 confirmation. Publication of original non-software thesis material is included in the author's selected complete-release scope; no new MIT grant over that material is created.
