## Caloric-restriction example

[extraction_fidelity_example.json — original path `extraction_fidelity_example.json`; withheld](../../rights/WITHHELD_FILES.csv) preserves the full original mini-baseline response, source and claim 013 for task 212. The response says it “does not provide direct evidence that CR universally lowers methylation age across all tissues, time points, or species”; the extracted claim affirmatively states that caloric restriction universally lowers methylation age. Both judges label that extracted claim NOT_IN_SOURCES and its citation UNSUPPORTED. The source abstract reports specific attenuation of drift and apparent younger blood methylation age, not the universal assertion.

This is an illustrative meaning/negation loss, not an estimate of error frequency. Repeated labeling of the same altered proposition cannot validate extraction. No original claim, verdict or judge label was changed. Stable IDs and complete texts support inspection against the canonical [consensus — original path `../../outputs/scifact_confirmatory_v3_2/atomic_consensus_v3_9/atomic_consensus.jsonl`; withheld](../../rights/WITHHELD_FILES.csv) and [generation records — original path `../../outputs/scifact_confirmatory_v3_2/results.jsonl`; withheld](../../rights/WITHHELD_FILES.csv).

Both generator families also serve as judges. Type consensus requires unsupported agreement plus an agreed type; only 53 of 261 consensus-unsupported claims receive an agreed type. Citation support uses at least one supporting attached source, not every claim–citation pair. Original [measurement diagnostics](../../outputs/scifact_confirmatory_v3_2/source_misrepresentation_analysis_v1/measurement_diagnostics.json) retain 197 no-attached-ID/unsupported-label discrepancies and 32 cited one-judge-nonfactual claims. Human review is separately documented in [G](../G_Human_Audit/README.md).
