## Original primary and sensitivity outcomes

[primary_and_sensitivity_effects.csv](primary_and_sensitivity_effects.csv) extracts the six model–strategy contrasts from the saved [atomic summary](../../outputs/scifact_confirmatory_v3_2/atomic_consensus_v3_9/atomic_consensus_summary.json), including primary consensus, either-judge and supported-content point estimates/intervals. Numeric values and existing four-decimal bounds are preserved without recalculation or rerounding. Proportions are not percentage points; multiply by 100 only for a display explicitly labelled in percentage points.

[verdict_and_agreement_outcomes.csv](verdict_and_agreement_outcomes.csv) preserves recognized/correct verdict counts and saved agreement values. Mini Structured has 83/98 recognized correct verdicts; mini CoV has 91/99. Other conditions have 100 recognized verdicts. [Original integrated CSV](../../outputs/scifact_confirmatory_v3_2/study_analysis/strategy_results.csv) and [JSON](../../outputs/scifact_confirmatory_v3_2/study_analysis/study_summary.json) remain canonical; their original Markdown has unescaped pipe-containing condition names and should not be trusted for column alignment.

[exploratory_evidence_condition_effects.csv](exploratory_evidence_condition_effects.csv) contains the 24 stored paired contrasts by evidence condition, each based on 25 tasks per model–strategy cell. [evidence_condition_means.csv](evidence_condition_means.csv) gives the 32 stored descriptive means, not paired effects or interactions. Fine-grained type consensus is limited: 208 of 261 consensus-unsupported claims have no agreed dominant type.

## Citation analysis, separately identified

The subsequent source-misrepresentation analysis is not the original primary endpoint. [Canonical source index](canonical_source_misrepresentation_index.json) identifies its six files by root-relative path and hash. Direct links: [complete report](../../outputs/scifact_confirmatory_v3_2/source_misrepresentation_analysis_v1/analysis_report.md), [paired estimates](../../outputs/scifact_confirmatory_v3_2/source_misrepresentation_analysis_v1/paired_contrasts.csv), [condition means](../../outputs/scifact_confirmatory_v3_2/source_misrepresentation_analysis_v1/condition_summary.csv), [response-level counts](../../outputs/scifact_confirmatory_v3_2/source_misrepresentation_analysis_v1/response_metrics.csv), [diagnostics](../../outputs/scifact_confirmatory_v3_2/source_misrepresentation_analysis_v1/measurement_diagnostics.json) and [settings/results](../../outputs/scifact_confirmatory_v3_2/source_misrepresentation_analysis_v1/analysis_summary.json). These files are linked rather than duplicated.

Consensus mismatch requires both citation labels UNSUPPORTED; either-judge requires at least one. Denominators are cited evaluable claims within each response, then averaged. Attachment coverage uses all evaluable claims. Missing IDs, valid IDs and semantically unsupported attribution are distinct. Original pooled agreement-resolved coverage is not physical attachment. All observed contrasts retain 100 pairs/75 source clusters; 2,000 pointwise replicates use analysis seed 20261010. Intervals condition on automated labels and are unadjusted for multiplicity.

[Saved request audit](../E_Reproducibility/saved_request_audit.json) identifies the seven incomplete GPT-5.5 verification steps at 1,600 output tokens; all downstream final records completed.
